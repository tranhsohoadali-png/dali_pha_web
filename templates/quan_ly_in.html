Khoá agent: —
Cách cài agent ở xưởng (làm 1 lần)
  1. Trên màn hình máy A1: bật Cài đặt → General → LAN Only Mode. Ghi lại Access Code (mục WLAN) và Serial (mục Device) của từng máy.
  2. Vào tab Máy in ở trên, điền Serial cho từng máy (để web ghép đúng trạng thái). Không cần nhập Access Code lên web.
  3. Trên 1 PC ở xưởng (cùng WiFi với máy in), cài Python 3 rồi tải gói bambu_agent, chạy: pip install -r requirements.txt.
  4. Mở config.json: dán Khoá agent ở trên, và điền IP + Access Code + Serial từng máy. Chạy python bambu_agent.py (hoặc bấm run.bat). Để agent chạy nền là xong.
Máy A1 chỉ cho 2–3 kết nối cùng lúc — khi agent chạy, tắt Bambu Studio/Handy nếu bị rớt. Access Code chỉ nằm ở PC xưởng, không lưu trên máy chủ.
