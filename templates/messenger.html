Các bước làm (một lần duy nhất)
  1. Vào developers.facebook.com/apps → Create App → chọn loại Business.
  2. Trong app, thêm sản phẩm Messenger → mục Access Tokens → chọn Fanpage của bạn → bấm Generate Token. Chép token đó vào ô Page Access Token bên dưới.
  3. Mục App Settings → Basic → chép App Secret vào ô bên dưới (dùng để chống giả mạo webhook).
  4. Tự nghĩ một chuỗi bất kỳ (vd dali-2026) điền vào ô Verify Token bên dưới rồi bấm Lưu.
  5. Quay lại Messenger → Webhooks → Add Callback URL:
    Callback URL: {{ webhook_url }}
    Verify Token: chuỗi bạn vừa đặt ở bước 4
  6. Bấm Verify and Save → sau đó Add subscriptions cho Page, tích messages và messaging_postbacks.
  7. Nhắn thử vào Fanpage bằng tài khoản khác → tin sẽ hiện trong Hộp thư.
